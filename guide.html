API Key Setup Guide

Follow these step-by-step instructions from A to Z to retrieve your credentials.

⚠️ Important Notice: This application utilizes a Gemini-only configuration. It explicitly relies on Google's Gemini models for visual proof auditing and does not support or integrate with alternative LLM providers.

1. How to Get Your Gemini API Key (Google AI Studio)

  1. Open your browser and navigate to Google AI Studio.
  2. Sign in using your Google account. Review and accept the terms of service if prompted.
  3. Look at the left-hand navigation menu or toolbar.
  4. Click on Get API key (or navigate directly to AI Studio API Keys).
  5. Click **Create API key**. Choose to associate it with an existing project or create a default new one.
  6. Copy the generated key string (starts with AIzaSy...) and paste it into Geminoist.

2. How to Get Your Todoist API Token

  1. Go to Todoist and log into your account.
  2. Click on your Profile Avatar in the corner of the web interface.
  3. Select Settings from the menu.
  4. In the Settings menu, click on the Integrations tab.
  5. Click on the Developer sub-tab.
  6. Find your API token and click Copy.
